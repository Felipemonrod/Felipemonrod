#### `caso_01` HEAD X — treinador de missão para jovens astronautas

Jogo de decisões em que crianças de 7 a 12 anos comandam uma base na Lua e sentem as trocas
reais de uma missão espacial: ar, energia, comida e radiação. O clima espacial da partida vem
de explosões solares reais registradas pela NASA e pela NOAA.

`NASA Space Apps 2026` · React · TypeScript · three.js · PWA · Vitest<br>
→ [código](https://github.com/Felipemonrod/nasa_education_hackaton) · [estudo de caso](https://felipemr.com/caso/head-x)

#### `caso_02` Camaleão SOS — protocolo de emergência por voz, offline

Aplicativo de proteção discreta para situações de violência doméstica: interface camuflada de
calculadora e detecção de uma frase de segurança no próprio aparelho, sem enviar áudio para a nuvem.

`protótipo · 2026` · Kotlin · Android · Vosk · sherpa-onnx · Node.js<br>
→ [código](https://github.com/Felipemonrod/camaleao-sos) · [estudo de caso](https://felipemr.com/caso/camaleao-sos)

#### `caso_03` Beyond of Mysteries — infraestrutura e documentação

Infraestrutura, documentação e operação do servidor de um projeto de jogo comunitário.
O código e os dados são privados; o estudo de caso conta o que dá para contar.

`desde 2025` · Linux · Docker · Node.js<br>
→ [estudo de caso](https://felipemr.com/caso/beyond-of-mysteries)
